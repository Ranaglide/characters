# Ranaglide characters info

This is my characters list pet-project.

This project shows using of api ([genshin.dev API](https://github.com/genshindev/api)).

Also it's good example of using DOM operations and multi-layered elements.

❗ IMPORTANT ❗<br>
genshin.dev API doesn't work from IP Adresses for some providers. You can try different to make it work.
And also this api for some reason doesn't have some images for few characters (Mualani, Kachina and maybe more)

It is available on github pages: [Here](https://ranaglide.github.io/characters)
